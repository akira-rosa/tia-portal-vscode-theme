# Archive

Earlier theme experiments, kept for reference. They are not part of the extension.

| File | What it was |
|---|---|
| `themes/tia-portal-portal-view-color-theme.json` | v1.0 "Modern" **Portal View** — light theme with Siemens petrol accents |
| `themes/tia-portal-project-view-color-theme.json` | v1.0 "Modern" **Project View** — dark petrol theme |
| `themes/tia-portal-classic-project-view-color-theme.json` | v1.1 Classic Project View |
| `themes/tia-portal-classic-portal-view-color-theme.json` | v1.1 Classic Portal View (navy/slate) |
| `css/tia-portal-classic.css` | v1.1 CSS layer for the two Classic themes |
| `scripts/` | the generators that produced them |

To try one again, add an entry for it under `contributes.themes` in `package.json`.
